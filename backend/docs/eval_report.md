# Phase 2 评估报告

## RAG 检索质量

| 指标 | 数值 |
|---|---|
| Recall@5 | 1.000 |
| Hit Rate | 0.892 |
| MRR | 0.883 |

测试集：10 条 query-文档对，K=5。

## Agent 路由准确率

| 指标 | 数值 |
|---|---|
| 严格准确率 | 0.857 (12/14) |
| 宽松准确率 | 0.857 (12/14) |

测试集：14 条 query，覆盖 4 类派活场景（Intake/Training/Nutrition/Recovery）+ 3 类不派活场景（闲聊/超范围/自我介绍）。

剩余 2 条"错误"性质分析：
- "我是新手，175cm 70kg，想减脂，家里有哑铃" → 派给 Intake 采集（合理）
- "我想减脂，帮我制定训练和饮食计划" → 派给 Intake+Nutrition+Training（多派，方向正确）

**结论**：无"错派"案例，均为"多派"或"先采集再规划"的保守策略。
